# Support

Use the right channel for the right kind of problem.

## Bug Reports

Open a GitHub issue if you can reproduce a bug in the current repository state.

Include:

- what you expected
- what happened instead
- the model or deployment path involved
- logs, responses, or screenshots when useful
- steps to reproduce

## Feature Requests

Open a GitHub issue with the problem you are trying to solve, not just the solution you want.

The most helpful requests explain:

- the use case
- why the current behavior is insufficient
- whether the request affects local workflows, the API, or GCP deployment

## Security Issues

Do not file public issues for vulnerabilities.

See [SECURITY.md](SECURITY.md) for private reporting instructions.

## Commercial or Product Context

This project powers embeddings for [flow-like.com](https://flow-like.com).

If your question is about Flow-Like product usage rather than this repository specifically, use the Flow-Like contact channel at `contact@flow-like.com`.
